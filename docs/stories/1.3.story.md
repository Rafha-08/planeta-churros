# Story 1.3 — Configurar Google Sheets como base de dados

**Epic:** 1 — Fundação
**Status:** Draft
**Agente:** @devops (Gage)
**Depende de:** Story 1.1

---

## Descrição

Como equipe do Planeta Churros,
quero ter uma planilha Google Sheets conectada ao n8n,
para registrar métricas, ações automáticas e relatórios de campanhas.

---

## Acceptance Criteria

- [ ] Planilha "Planeta Churros — Meta Ads" criada no Google Drive
- [ ] Abas criadas: Campanhas, Métricas Diárias, Ações Automáticas, Relatório Semanal
- [ ] Google Sheets conectado ao n8n via credencial OAuth
- [ ] Teste de escrita bem-sucedido: n8n registra uma linha de teste na planilha
- [ ] Planilha compartilhada com a equipe

---

## Tasks

- [ ] 1. Criar planilha no Google Sheets: "Planeta Churros — Meta Ads"
- [ ] 2. Criar aba "Campanhas" com colunas: ID, Nome, Status, Orçamento, Início, Fim
- [ ] 3. Criar aba "Métricas Diárias" com colunas: Data, Campanha, Impressões, Cliques, CTR, CPC, Gasto, ROAS
- [ ] 4. Criar aba "Ações Automáticas" com colunas: Data/Hora, Campanha, Ação, Motivo
- [ ] 5. Criar aba "Relatório Semanal" com colunas: Semana, Total Gasto, Total Cliques, Melhor Campanha
- [ ] 6. No n8n, adicionar credencial Google Sheets (OAuth2)
- [ ] 7. Criar workflow de teste: escrever linha "Teste OK" na aba Ações Automáticas
- [ ] 8. Compartilhar planilha com e-mail da equipe
