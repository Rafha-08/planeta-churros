# Story 1.4 — Criar Fluxo 4: Controle de Orçamento Diário

**Epic:** 1 — Fundação
**Status:** Draft
**Agente:** @dev (Dex)
**Depende de:** Stories 1.1, 1.2, 1.3

---

## Descrição

Como Rafha (dona do Planeta Churros),
quero que o sistema monitore o gasto diário no Meta Ads automaticamente,
para que nunca ultrapasse o limite de R$1.000/mês sem minha aprovação.

---

## Acceptance Criteria

- [ ] Fluxo executa automaticamente todos os dias às 8h
- [ ] Fluxo busca o gasto total do mês corrente via Meta API
- [ ] Se gasto > 90% do limite (R$900): pausa TODAS as campanhas ativas + envia alerta WhatsApp
- [ ] Se gasto entre 70-90% (R$700-900): envia aviso de atenção no WhatsApp
- [ ] Se gasto < 70%: registra status normal no Google Sheets
- [ ] Todas as ações são registradas na aba "Ações Automáticas" do Google Sheets
- [ ] Limite de orçamento configurável sem precisar editar o fluxo

---

## Tasks

- [ ] 1. No n8n, criar novo workflow: "Fluxo 4 — Controle de Orçamento"
- [ ] 2. Adicionar nó Schedule Trigger: todo dia às 8h
- [ ] 3. Adicionar nó Facebook Graph API: buscar gasto do mês (`/act_{ID}/insights?fields=spend&date_preset=this_month`)
- [ ] 4. Adicionar nó IF: verificar se gasto > R$900
- [ ] 5. Adicionar nó Facebook API: pausar campanhas (`status: PAUSED`)
- [ ] 6. Adicionar nó IF: verificar se gasto entre R$700-R$900
- [ ] 7. Adicionar nó WhatsApp/Telegram: enviar alerta com valor gasto e % do limite
- [ ] 8. Adicionar nó Google Sheets: registrar ação na aba "Ações Automáticas"
- [ ] 9. Configurar variável de ambiente: `ORCAMENTO_LIMITE=1000`
- [ ] 10. Testar fluxo manualmente antes de ativar agendamento
- [ ] 11. Ativar fluxo em produção
