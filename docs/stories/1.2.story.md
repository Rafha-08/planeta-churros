# Story 1.2 — Conectar Meta Marketing API ao n8n

**Epic:** 1 — Fundação
**Status:** Draft
**Agente:** @devops (Gage)
**Depende de:** Story 1.1

---

## Descrição

Como equipe do Planeta Churros,
quero conectar a conta do Meta Ads ao n8n,
para que os fluxos possam criar, pausar e monitorar campanhas automaticamente.

---

## Acceptance Criteria

- [ ] App criado no Meta for Developers com permissões de Marketing API
- [ ] Token de acesso gerado e válido
- [ ] Credencial do Meta configurada no n8n (Credentials > Meta)
- [ ] Teste de conexão bem-sucedido: listar campanhas ativas via n8n
- [ ] ID da conta de anúncios salvo no n8n como variável

---

## Tasks

- [ ] 1. Acessar https://developers.facebook.com e criar App do tipo "Business"
- [ ] 2. Adicionar produto "Marketing API" ao App
- [ ] 3. Gerar token de acesso com permissões: `ads_management`, `ads_read`, `business_management`
- [ ] 4. No n8n, ir em Credentials > Add Credential > Facebook Graph API
- [ ] 5. Colar o token e salvar
- [ ] 6. Criar workflow de teste: listar campanhas da conta `planeta-churros`
- [ ] 7. Salvar o `Ad Account ID` como variável no n8n

---

## Notas

- O Ad Account ID começa com `act_` seguido de números
- Pode ser encontrado em: Gerenciador de Anúncios > URL da página
- Token de acesso longa duração válido por 60 dias (renovar antes de expirar)
